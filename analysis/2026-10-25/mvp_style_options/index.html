五个风格方案对比

同一套示意数据和交互，五种风格。这一轮按外部评审意见重排了信息架构：先选资产，每种资产按"决定 → 改进 → 证明"三步看；计划能不能执行、哪些操作是排定的、哪些取决于价格、每个结论的范围，都放到第一屏。点截图或"打开原型"进入；原型底部的黑色切换条可以在五个方案之间切换，并停留在同一页。

方案截图都是 1440×900 屏幕的第一屏，其余截图从页面里裁出。所有数字都是示意，原型没有接模型。

这一轮改了什么

决定 · Plan / Tonight's call计划能不能执行；建议操作分"排定"和"条件"两行；预计净值、晚间放电、约束三个数字；一天的时间轴；为什么这样排。
改进 · Compare / Value比基准每天多赚多少（默认看测试期 +A$350/天），或自定方案比参考条款多给 Zenith 多少；下面一行写明范围。
证明 · Validation硬限值、样本外证据、信息时点三个结果放在最上面，检查表在下面，每个结果写明时间段和运行编号。
评审的问题核对结果和做法
调度说得太确定部分对。正式模型里计划的 7.5 MW 晚间放电是排定的，每 30 分钟按最新价格重排；只有计划之外的富余电量从 A$150/MWh 起分层报价，价格到了才卖。页面按这个分两行写；条件部分不计入预计净值。出处见 README。
验证有 Fail，首页却给收益那个 Fail 是原型占位数据，真实回测里正式配置没有违反接入上限；改成"0 次违反"，合同最大需量（CMD，按电费计价的经济限值）单独一行，只警告、不拦计划。另外把"结果是否最新"和"计划能否执行"分成两个状态；计划违反限值时首页显示"Plan blocked"，预计净值改标"Simulation only"（见下图，设置里把出口上限改成 3 MW 即可看到）。
两种商业模式混在一起对。顶栏先选工厂电池或客户电池群，每种只显示自己的三个页面；设置放到齿轮后面。
验证对商业结论支持不够对。收益页的结论下面写明：历史模拟、样本内、假设情景、运行 R‑0142、还没有样本外检验；7 天的未看过测试期显示"区间包含 0"。

详细图表（五个方案共用）

读法
颜色代表一个量。虚线是计划或预测，实线是实际发生的。坐标轴写单位，上下限标在线尾。
交互
鼠标移到图上，两张图同时出现竖线，并弹出数值表格（见下图）。点图例可以隐藏或显示一条线。右上角可以下载 CSV。点某个时刻，给出一句原因。

A 极简·聚焦 打开原型 →

布局
顶栏放资产切换、该资产的三个页面、结果状态和设置。页面是一条居中的阅读栏：计划状态、建议操作和三个关键数字、一天的时间轴、为什么这样排，下面才是详细图表。不加卡片框，只用细分隔线。
适合
演示时一页一页地讲。投影和打印效果最干净。评审看的就是这一版。
代价
内容要往下滚，同一屏能看到的东西比 C 少。

B 编辑·简报 打开原型 →

布局
报头加栏目条，资产切换和页面放在栏目条里。每页像一篇简报：计划状态是一行通知，建议操作是衬线大标题，三个数字在事实框里，时间轴是图 1，详细图表是图 2，检查放在右侧旁注。改进页和收益页的大数字像标题数字。
适合
给评委和导师阅读，或截图放进报告。
代价
大号衬线标题占空间。不像操作软件，日常操作时找控件稍慢。

C 深色·控制台 打开原型 →

布局
每页固定在一屏内。计划页顶部一条横跨的格子放计划状态、建议操作和三个数字，下面一条时间轴，再下面三栏：左边为什么这样排和检查，中间两张图，右边所选时段和账目。高度不到 900 像素时左栏改成可滚动，不到 700 像素时整页滚动。
适合
运营人员一整天开着看。最像电力交易台。
代价
深色在投影和打印上效果差。信息密度高，第一次看的人需要适应。

D 柔和·卡片 打开原型 →

布局
悬浮侧栏：资产切换、该资产的三个页面（标着 Decide / Improve / Prove）、底部设置。计划页是一张宽的决定卡片（计划状态和建议操作），下面三张数字卡片、时间轴卡片、为什么卡片和图表卡片。
适合
第一次打开的人和非技术读者，最友好。
代价
卡片之间留白多，页面比 C 长；两张卡片底部各留白约 60 像素。

E 行业工具 打开原型 →

布局
照参考截图：产品栏；第一层标签是资产（工厂电池 / 客户电池群），第二层是该资产的页面；灰色筛选栏写市场、交易日和决策时刻，右边是结果状态和按钮。计划页先写资产名和"View inputs ›"，左边决定卡片和时间轴，右边三张数字卡片。
适合
让熟悉这类交易软件的人一看就知道怎么用。
代价
个性最弱，看起来像标准的商业软件。筛选栏只显示，不能改（原型只有一个交易日）。

五个方案都一样的地方

  • 页面、数字和交互一样，只有视觉和布局不同。上一版原型（mvp_product_design/wireframe.html）没有改动。
  • 七个页面：工厂电池的 Plan、Compare、Validation，客户电池群的 Tonight's call、Value、Validation，加上设置。旧链接会打开对应的新页面。
  • 顶栏的"Results up to date / stale"只说结果和输入对不对得上；"Plan executable / blocked"只说今日计划能不能执行。
  • 改了输入以后结果变灰，保存按钮变成重算，导出和 CSV 下载关闭。
  • B、C、D、E 由四个子任务按 A 并行改写；一个只读子任务核对了模型事实，另一个评审了全部页面，找到的 23 处问题改了 21 处（见 README）。五个方案都通过 39 项点击检查。
